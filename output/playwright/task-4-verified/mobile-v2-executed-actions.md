# Mobile v2 executed action record

This is the exact three-step Playwright CLI action sequence that produced `mobile-arrival-touch-v2.webm` in named session `task4-mobile-v2c`. The first step installed trusted canvas pointer listeners and started the screencast. The second used `Input.dispatchTouchEvent` at the live CTA center, released at progress >=35%, and waited for the application's automatic completion. The third waited for automatic `aria-pressed="true"`, issued trusted touch start/end at `(120,450)`, waited for `aria-pressed="false"`, retained 2.4 seconds of settle, stopped the screencast, and returned the result copied verbatim into `mobile-v2-capture-result.json`.
